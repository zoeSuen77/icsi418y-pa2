# PA2 操作与提交指南

## 先运行已经完成的本地版本

在终端进入项目目录（以下示例从项目的上级目录开始）：

```bash
cd icsi418y-pa2
npm ci
npm run demo
```

这台电脑已安装依赖时，可以直接运行 `npm run demo`。浏览器打开 **http://localhost:5173**。终端保持开启；按 `Ctrl+C` 可以停止。

`npm run demo` 会启动真实的 MongoDB、Express 后端和 React 前端。第一次需要联网下载 MongoDB，之后可以复用。数据保存在项目的 `.local-data/mongo`，正常关闭后再次运行仍会保留，因此重新录视频时请换一个新用户名。

注册要填写 First name、Last name、Username、Password。成功后可以登录；重复用户名会报错，错误密码也会报错。`Show` 可以切换密码显示。

## 查看数据库里的用户

演示保持运行，在第二个终端进入同一项目目录，运行：

```bash
npm run db:users -- --local
```

这个命令直接查询 MongoDB 中的前 20 条用户文档。查看特定用户或做图形化演示时，可以使用 MongoDB Compass，连接 `mongodb://127.0.0.1:27018`，打开 `pa2` 数据库下的 `users` 集合，按用户名筛选。

应看到 `_id`、`f_name`、`l_name`、`username`、`password`。密码字段是 `scrypt$...` 格式的哈希，不是明文，这不影响正常登录验证。

## 按老师指南切换到 MongoDB Atlas

本地版已经可以完成应用功能。老师的环境配置指南使用 Atlas，录制 Atlas 版本前需要你自己的数据库账户和连接串。

1. 登录 MongoDB Atlas，创建数据库部署和数据库用户。
2. 将当前电脑的 IP 加入 Atlas 的网络访问列表。
3. 在 Connect → Drivers → Node.js 中获取连接串。
4. 把 `server/.env.example` 复制为 `server/.env`，把 `MONGO_URI` 改成实际连接串。不要把密码发到聊天或提交到 GitHub。
5. 停止本地 demo，再运行 `npm run dev`。该命令读取 `.env` 中的数据库地址。
6. 注册新用户，在 Atlas 的 `pa2.users` 中刷新并查看。

`npm run demo` 固定使用本地数据库；`npm run dev` 才使用你配置的 Atlas。2026 年 9 月 24 日已在本机配置 Atlas，并通过浏览器验证注册、数据库写入、重复用户名检查和正确／错误密码登录。本机的连接串保存在 server/.env，未提交到仓库；在其他电脑运行时，需要配置自己的连接串和网络访问权限。

## 测试和代码理解

```bash
npm test
npm run build
PLAYWRIGHT_CHANNEL=chrome npm run test:ui
```

最后一条适用于这台装有 Chrome 的 Mac；其他系统可以先 `npx playwright install chromium`，再 `npm run test:ui`。

核心流程：React 使用 `useState` 保存输入 → `fetch` 把 JSON 发到后端 → Express 检查字段并查询 MongoDB → 后端返回状态码和消息 → React 显示结果。

`server/app.js` 是注册和登录逻辑，`server/server.js` 负责连接数据库，`server/passwords.js` 负责哈希。代码不会创建会话、JWT 或受保护页面，符合本次作业只需登录成功提示的范围。
